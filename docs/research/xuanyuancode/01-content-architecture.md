## 5. 转化漏斗：免费内容 → 星球变现

这是整站商业逻辑的核心，**用一个视觉信号（`免费` 绿标 vs `星球专属` 黄标）贯穿始终**：

```
①  免费引流层（占比最大）
    ├─ B站动画视频（85.6W 播放）→ 全网 50W+ 粉丝
    ├─ 免费博客 73 篇（SEO + 干货）
    ├─ 免费课程 ×4（大模型/Claude Code/AI编程互动+图文）
    └─ 免费工具（EasyTshark 2.5W+ 下载 / 代码全景图 / SVG工作室）
                    │  用「免费」建立信任与习惯
                    ▼
②  星球专属层（变现）
    ├─ 星球专属课程（AI视频智能体、代码分析智能体训练营，标 `星球专属`）
    ├─ 《从零开始学逆向》1200 学员、《C/C++抓包》800 学员、《VMP逆向》500 学员
    └─ 知识星球：¥299/年（限时 ¥279）＝ 全部课程 + 一对一答疑 + 资源共享
                    │  1700+ 成员 / 3400+ 主题 / 1700+ 运营天数
                    ▼
③  沉淀层
    ├─ 微信群（轻社群，招聘/内推/八卦）
    └─ 书籍《趣话计算机底层技术》（京东，品牌背书）
```

**漏斗设计的三个关键手法**：
1. **同款卡片、不同角标**：免费与付费内容用完全一致的卡片版式，只靠左上角 `免费`(绿) / `星球专属`(黄) 一个色标区分——让付费内容「看起来同样触手可及」，降低心理门槛。
2. **数据前置的社会证明**：Hero 数据条（50W+ 粉丝）、课程卡的学员数（1200/800/500）、星球页的 1700+ 成员，层层复用「已经很多人选择了」的从众效应。
3. **单一价格锚点**：星球页只有一个价格 `¥299/年（限时¥279）`，配「所有课程 + 答疑 + 资源」的打包权益，避免多套餐决策瘫痪。

## 6. 各子页面内容差异速记

- **`/ai-learning`**：6 门课程按 `01~06` 编号排列（有序学习路径感），每卡带更长的「学完能……」收益文案（如「学完真正看懂 ChatGPT 底层原理，读论文、调参、面试都更有底气」）。结尾放「更多教程正在路上」占位，营造持续更新预期。
- **`/articles`**：顶部统计 `8 分类 / 73 文章`，双视图（最新发布 / 近期更新），下方按分类分组的完整目录。
- **`/articles/{uuid}`**：左侧常驻「博客目录」侧栏（按分类 + 篇数），正文图文混排，顶部有面包屑式「返回博客」。
- **`/tools`**：分「原创开发」与「精选工具」两组，卡片统一 `立即使用 →`。
- **`/easytshark`**：标准 SaaS 产品页结构——Hero（版本号 `v1.0.2` + 一句话 slogan）→ 多平台下载按钮（Win/macOS Intel/macOS M/Ubuntu/在线版）+ 开源徽标 → 下载量数据（`25000+`）→ 版本历史/更新日志 → 核心功能网格（数据包列表/会话分析/进程关联…）→ 产品优势 → 适用场景（教学/排障/安全审计/性能优化）。
- **`/knowledge-planet`**：权益清单（★干货课程 ◎学习路径 ✦实战案例 👥一对一答疑）→ 三个数据（1700+/3400+/1700+）→ 加入方式/价格/权益三栏 → 星球专属课程详情卡（含课程亮点、课时、更新节奏）。
