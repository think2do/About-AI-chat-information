Tokenizer 分词对比
以「你好」2个汉字为例，各模型每汉字消耗 token 数：
早期模型（~2021）
国外模型（GPT-3 等） 3.5 tokens / 汉字
国内模型（文心等） 1.0 token / 汉字
现在模型（~2024+）
国外模型（GPT-4o 等） 1.0 token / 汉字
国内模型（Qwen、DeepSeek 等） 0.5 token / 汉字
💡 从早期到现在，国外模型中文 token 效率提升了 3.5×；国内模型持续领先，甚至达到 0.5 token/汉字（比英文还节省）。
早期模型（~2021），同等信息量下的分词效率：
国外模型（GPT-3）
中文 3.5 tokens / 字
你｜好｜，｜我｜是｜一｜个 → 24.5 tok
英文 0.27 tokens / 字母
Hello → 2 tok
国内模型（文心一言等）
中文 1.0 token / 字
你好 → 2 tok
英文 0.27 tokens / 字母
Hello → 2 tok
⚠ 早期国外模型的中文分词效率极低，同等中文内容消耗的 token 数约为英文的 13 倍。
现在模型（~2024+），同等信息量下的分词效率：
国外模型（GPT-4o）
中文 1.0 token / 字
你好 → 2 tok
英文 0.27 tokens / 字母
Hello → 2 tok
国内模型（Qwen、DeepSeek 等）
中文 0.5 token / 字
你好 → 1 tok
英文 0.27 tokens / 字母
Hello → 2 tok
✅ 现在国内模型的中文分词效率甚至超过了英文，0.5 token/字意味着使用中文反而比英文更省 token。
